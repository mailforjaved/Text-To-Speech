# Local Text to Speech Website

This site runs directly in your browser with no app server.

## How to run

1. Open `index.html` in Chrome or Edge.
2. The page automatically tries to load `dictionary.txt` from the same folder.
3. Optional: click **Choose Text File** to load a different `.txt` file.
4. Press **Play**.

## Features

- Local `.txt` file loading
- Auto-load `dictionary.txt` on page open
- Browser-native text to speech
- Voice picker
- Rate, pitch, and volume controls
- Play, pause, resume, and stop
- Line-by-line speaking
- Ignores lines starting with `#`
- Active line number while playing

## Notes

- Speech starts from a user click due to browser policies.
- Voice options come from your operating system and browser.
- If voices look empty at first, wait a second and re-open the voice dropdown.
